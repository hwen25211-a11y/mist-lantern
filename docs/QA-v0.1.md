# 验证记录

验证日期：2026-10-20。测试全程保持 Mac 静音，游戏也保持静音。编辑器自动化使用独立测试存档。

## 规则与完整路线

`docs/qa/rules.txt` 记录 44 项断言。覆盖移动归一化与边界、受伤与无敌、喝药、明暗切换、圆形及纵深条形攻击、唯一奖励、一次性领取、补给与换武器、险路、存档往返与损坏拒绝、结算幂等性、自然死亡。

三种武器分别执行种子 7、42、2026 的完整十二房间流程，共九条通关路线，含险路与战斗中序列化恢复。使用正常移动、攻击、闪避、技能和药水输入，不直接设置敌人死亡或玩家胜利。

## Unity 场景与 UI

`docs/qa/play-results.txt` 记录实际 Play Mode 检查：通过 EventSystem 的指针射线点击新游戏、武器、暂停、继续、奖励、补给、路线、遗物页、营地升级、失败重开和胜利返回。三种武器各自完整运行十二房间。战斗由测试输入驱动实际 Game.Update，采用固定 0.05 秒测试步长；这部分是加速自动化，并非人工键鼠试玩。

场景截图在 `docs/screenshots`。检查中文文字溢出、单个环境音乐源、静音测试保护，以及暂停后生命和游戏时间不变化。

最终代码整轮回归：229 条交互与运行断言通过，54 次界面截图审查，`PLAY_OK errors=0 overflow=0`。本轮后续增加的模型陈列场景仅用于编辑器展示，不改动运行时战斗逻辑。

## 实际浏览器键鼠试玩

在本地 HTTP WebGL 构建中，通过浏览器真实鼠标和键盘操作完整冒险：

- 初始武器为引星灯杖，种子 **1808427899**，无永久升级。
- 从房间 1 到房间 12，击败三位首领，最终击败敌人 65。
- 庭院选择一次险路并打完额外第三波，其余选择普通道路。
- 使用持续键盘攻击、鼠标按住攻击、移动中攻击、闪避、跳跃、武器技、明暗切换和药水。
- 按 Esc 暂停与继续；在第二位首领奖励处刷新页面、更新构建，然后恢复到同一奖励状态，生命与遗物保留。
- 最终抵达胜利页：战斗计时 02:14，生命 104 / 180，营地余烬 95。计时不包含暂停、奖励与路线选择时间。
- 胜利截图：`screenshots/web-complete-victory.jpg`。胜利后在工坊消费 15 余烬购买一级生命成长，重新出发的最大生命为 132。
- 另开一局重锤，实际操作移动、近战、闪避和跳跃后，停止抵抗自然死亡（00:27，生命 0 / 132）；失败结算、再次出发、暂停保存与返回扉页均完成。证据为 `web-natural-death.jpg` 和 `web-restart-pause.jpg`。

浏览器完整游玩过程中发现 WebGL 裁剪造成的 `SphereCollider` 错误。已将纯视觉粒子和危险提示改为直接创建网格，不再调用运行时 `GameObject.CreatePrimitive`。恢复该局后完成钟楼区域与最终首领，又从首房间验证近战、自然死亡与重开，修复后日志错误数为零，见 `qa/web-fixed-console.json` 和 `qa/web-fixed-errors.json`。

## 本轮发现并修复

1. 中文字体行高导致标题和 HUD 标签溢出：调整文本容器最小高度，重新生成字体图集。
2. 新 UI 生成当帧，自动化射线尚未稳定：测试等待下一帧后再点击；完整界面流程重新运行。
3. 换区域时延迟销毁的旧场景与新场景重叠一帧：销毁前立即停用，清除跨房间的粒子、飘字与危险提示。
4. 默认 WebGL 网页在窄视口裁切：替换为自适应 16:9 画布；检查常规窄侧栏与 1280×800 桌面视口。
5. 发布版粒子创建依赖被裁剪的碰撞类型：改为无碰撞组件的网格构造，重新构建并实际战斗回归。

## 验证范围

macOS 与 WebGL 均使用 Unity 实际构建。Mac 原生窗口已检查启动、中文与画面；当前原生桌面自动化未成功驱动该窗口，不能将其计为 Mac 原生完整键鼠通关。完整键鼠通关证据来自 WebGL。Windows 原生执行文件不在本次构建平台范围内。

本地 HTTP 返回的 HTML、loader、framework、data 和 WASM 与构建文件逐字节相同，WASM MIME 正确；同一服务复用、无关端口占用拒绝均通过。证据：`qa/http.json`。压缩包由 `Tools/package.py` 逐项校验 CRC 和 SHA256，并检查 Mac 可执行权限，汇总于交付目录的 `checksums.json`。

所有“通过”结论仅指这里记录的版本与测试路径，不作未经验证的全平台零缺陷承诺。
