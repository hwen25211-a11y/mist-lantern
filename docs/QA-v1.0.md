验证日期：2026-10-21。Unity 2022.3.62f3c1，macOS 本机与 WebGL 浏览器。系统输出音量为 0、输出静音为 true；原生和编辑器测试使用 `-silent-test`，运行时遥测确认静音。

## 修复与复查

| 问题 | 处理与验证 |
| --- | --- |
| 近战按下即扣血，动画随后摆动 | 分开准备、命中和回收，并让动画接触相位跟随真实命中时刻；专项与实机复查 |
| 连续攻击中点技能被收招吞掉 | 短输入缓冲；普通攻击期间和顿帧期间的一次输入均有专项覆盖，实机再验证 |
| 大首领被轻击逐渐推离有效距离 | 轻攻击不推动大首领，重击保留小幅反馈；受击范围与体型配合 |
| 法杖近身射点越过重叠目标 | 前移距离缩短，增加贴身回归；技能贯穿按目标 ID 去重 |
| 部分自制网格出现黑面 | 修正板片与圆环面朝向，重新导出并检查三个区域和模型展示 |
| 新地表被基础网格遮挡 | 调整高度和范围，复查真实场景截图 |
| 遗物图集边界串入相邻图案 | 重排图集、使用各区域 UV 边界并保留比例，复查奖励卡片 |
| 遗物说明范围不够明确 | 明确震波限近战末段、夜行围巾的无敌时长不重复延长 |
| 历史敌人血条持续累积 | 移除离开房间的血条对象 |
| 一次 WebGL 增量构建工具退出 138 | 后续重新构建成功；最终包仅采用成功产物，并核对实际 HTTP 内容 |

## 交付检查与范围

源码、模型、材质、绘画资产、字体许可、场景、工具与说明纳入 Git；Library、Build、release 和用户存档不纳入源码版本控制。模型陈列场景及三个区域截图已经检查，标题原画不作为实际游戏画面的质量证据。

`Tools/package.py` 对压缩包检查 CRC、逐文件 SHA256 和 Mac 可执行权限；`Tools/verify_release.py` 核对构建、版本、源码摘要、通关证据及 HTTP 内容。打包清单见 release/checksums.json。

测试中的操作失误造成角色死亡属于正常失败分支。记录区分自动化与真实输入、失败与胜利；没有把未测平台、输入设备或任意未来环境写成已通过。游戏逻辑修复后完成回归，最后的说明文字澄清不改变战斗规则。
