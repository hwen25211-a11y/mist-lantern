# 雾灯遗城

本文记录 v0.1.0 的已实现设计。该版本的模型、场景与动作质感未通过质量验收；重做依据与后续方向见 [失落城堡 2 调研](research/LOST-CASTLE-2.md)，其中的新设计尚未实现。

## 核心体验

固定斜侧镜头的纵深动作战斗，三个区域、十二个节点组成一次冒险。玩家在清场后选择遗物，再决定下一房间走普通道路还是进入额外奖励的险路。每四个节点有一场区域首领战。失败带回少量余烬，能在扉页购买永久成长，再次出发。

参考 Lost Castle 2 的动作肉鸽类型、武器差异、掉落构筑与首领节奏；角色、场景、故事、遗物和明暗机制为本项目原创。参考页：https://store.steampowered.com/app/2445690/Lost_Castle_2/

## 区别

明灯消耗灯油，照破幽影敌人的雾甲；暗灯恢复灯油，但幽影更难打。两种状态都能移动、攻击、闪避和使用技能。灯油同时是武器技的资源，构筑围绕明灯输出、暗灯回复和切换爆发展开。

弯刀快速三连击，重锤慢速广域击退，灯杖发射可躲避弹体。每种武器有不同的技能范围和资源消耗。首领的预警区域同时表示攻击方向和纵深。

## 美术

浓雾蓝 #152A38、旧铜 #B89962、灯焰金 #FFD28C、朱砂红 #AD5449、釉青 #559B9B。
界面主体使用获 SIL OFL 许可的 Noto Sans SC 衍生字体；标题使用放大字距，HUD 用清楚的数字层级。
造型的标志是大兜帽、红围巾、铜灯与白瓷面具。角色有分部件动画；环境用拱桥、钟面、齿轮和树冠建立不同区域的轮廓。所有地面危险提示都位于实际伤害范围。

## 验收

规则测试覆盖攻击、距离、闪避、明暗切换、奖励、随机种子、流程与存档。
Unity Play Mode 覆盖实际场景、菜单、暂停、失败、胜利和中文显示。
发布构建通过真实窗口输入完整游玩，保留截图与操作记录。重测修复后的分支。测试全程静音，测试保存独立于用户保存。
