雾灯遗城 · v1.0.0

Mac 版：解压后打开“雾灯遗城.app”。
浏览器版：解压整个文件夹，在安装 Python 3 的电脑上双击对应启动器。
也可以在解压目录运行 python3 Tools/preview.py，再访问 http://127.0.0.1:8920 。
不要直接双击 WebGL/index.html，Unity WebGL 需要通过本地 HTTP 服务加载。

WASD / 方向键：移动（有纵深）
J / 鼠标左键：攻击，可按住
K / Shift：闪避
Space：跳跃
L / 鼠标右键：武器技
Q：明暗提灯切换
R：放灯 / 收灯
C：格挡，起手瞬间可精准格挡
F：喝药
I：查看遗物
Esc：暂停
Enter：菜单确认；1—3：选择武器、遗物、补给或工坊升级
扉页 W：工坊；H：手册；N：新冒险；菜单 Esc：返回

明灯在光区内照破幽影的雾甲；暗灯可以快速回油。
放置灯能吸引部分敌人，但它们会扑灯并消耗灯油。
重锤按住蓄力，松开或蓄满挥击；技能点按可以在收招期间衔接。
攻击和技能会自动朝向附近目标，但仍需要保持合适距离。
敌人脚下的红色预警表示真实攻击区域；离开、闪避或跳过。
清场后选遗物，补给点选疗伤、强化或换武器，每四个房间挑战一位首领。

游戏默认静音，声音开关位于扉页和暂停菜单。
房间、奖励、暂停和退出会保存，战斗中每八秒保存一次。
浏览器存档与 Mac 存档相互独立；浏览器版请保持同一地址和端口。
