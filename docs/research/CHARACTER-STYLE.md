以下是视觉观察和本项目的制作判断，不是原作官方公布的数值规范：

| 项目 | 原作实机的视觉特点 | 本项目调整 |
| --- | --- | --- |
| 比例 | 大头、紧凑躯干和短四肢；装备显著影响外轮廓 | 全身约 2.7–3 个含发型头高，短而有力量的四肢 |
| 表情 | 图形化眼眉和口型，在较小像素高度仍可读 | 保留清楚眼眶和颌面拓扑，概括鼻唇，不用真人脸和幼儿脸 |
| 头发 | 成组的大块尖发束，轮廓明确 | 实体发束，移除写实碎发与透明毛发卡片 |
| 服装装备 | 大形体、重叠层次、明暗块和边缘线 | 短披肩、厚肩甲、短衣摆、大手套、大靴子；细节服务于轮廓 |
| 材质 | 漫画色块与有控制的高光 | 减弱密集织纹、碎噪声，强化厚度和主次分明的色块 |
| 游戏镜头 | 脸和武器在远景中仍可识别 | 先看实机相近像素高度，再看模型近景 |
