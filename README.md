# 雾灯遗城 · Mist Lantern

Unity 2022.3.62f3c1 / C#，中文单机 2.5D 动作 Rogue-lite。

扮演最后一名守灯人，穿过暮色旧桥、萤雾庭院与停摆钟楼，让第十三声钟再次响起。三种武器、三片区域、十二个节点、三位独立首领、十二种遗物（多数可叠加）、普通与险路、补给和营地成长组成一次完整冒险。

## 启动

- macOS：`Build/macOS/雾灯遗城.app`。
- 浏览器：运行 `python3 Tools/preview.py`，打开 http://127.0.0.1:8920 。保持这个地址和端口，存档才能延续。
- 源工程：Unity Hub 打开本目录，使用 `Assets/Scenes/MistLantern.unity`；`ModelGallery.unity` 展示可编辑模型。
- 交付包位于 `release`，版本以包名和 `BUILD-INFO.txt` 为准。

游戏默认静音。测试要求、实际覆盖与修复记录见 [QA.md](docs/QA.md)。

## 操作与战斗

| 按键 | 操作 |
| --- | --- |
| WASD / 方向键 | 移动；注意前后纵深与脚下位置 |
| J / 鼠标左键 | 攻击；可按住，重锤会蓄力后挥击，也可以松开提前出手 |
| K / Shift | 闪避；带方向输入可以指定方向 |
| Space | 跳跃，躲避地面攻击 |
| L / 鼠标右键 | 武器技；消耗灯油，收招末段可提前输入衔接 |
| C | 按住格挡；起手瞬间成功可精准格挡、回油和积累资源 |
| Q | 明暗切换：明灯在光区内破雾甲，暗灯恢复灯油 |
| R | 放灯 / 收灯；放置后光区留在原地，部分敌人会攻击灯并消耗灯油 |
| F / I / Esc | 药水 / 遗物 / 暂停 |
| Enter / 1—3 | 菜单确认 / 武器、遗物与补给选择；扉页 W 工坊、H 手册 |

弯刀通过三段连击和格挡积攒锋意，强化追斩；重锤蓄力越足伤害越高，并能破势打断；灯杖命中蓄星，满星强化弹体，武器技能贯穿多个目标。攻击自动朝向附近目标，仍需靠近并对准纵深。

## 制作与来源

主角按已确认的守灯人设计稿，通过本地 AI 辅助三维重建、四视图绘制、纹理烘焙、肩甲拆分和骨骼绑定制作，保留可编辑 Blender 源文件；具体来源、许可及重建步骤见 [角色来源](ArtSource/Characters/README.md)。这不是学生从零手工雕刻的人物。提灯、弯刀、背包装备、敌人和环境部件由项目代码生成并导出为真实三维网格。背景、地表纹理和遗物图标使用 AI 辅助制作，说明见 [ART-V1.md](docs/ART-V1.md) 和 [实体模型与材质来源](docs/ART-SCULPT.md)。字体许可见 `Licenses`。

参考游戏的调研、版本差异和设计依据见 [失落城堡 2 调研](docs/research/LOST-CASTLE-2.md)。原作截图和视频没有作为游戏素材打包。
