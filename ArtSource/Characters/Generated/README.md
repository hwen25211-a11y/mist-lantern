# Reconstruction provenance

`HunyuanMLX/keeper-shape-candidate.glb` is the actual locally generated source geometry used for the Keeper. It is a shape-only output; the project separately performs texture projection, atlas baking, shoulder-shell separation, bone-heat corrections, rigging and Unity integration. Its original candidate filename is retained for provenance. `generation.json` records seed, runtime, settings and verified weight identity. Model/port licenses and source revisions are included; model weights remain outside the project.

`Pixal3D/generation.json` records an anonymous demo attempt rejected by quota. The later authenticated Edge attempt produced a preview, but export failed with “The requested GPU duration (240s) is larger than the maximum allowed”. `browser-generation.json` preserves that result. No Pixal3D GLB was obtained or used. The user requested continuing locally without purchasing GPU service.

The approved design is `../Concept/keeper-cartoon-v1.png`. A successful generator run alone is not visual or gameplay acceptance; actual Unity renders and current test evidence are kept separately.
